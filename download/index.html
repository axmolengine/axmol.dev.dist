Axmol Hub Early Access

Axmol Hub is the official companion tool that installs and manages engine releases, toolchains, and build targets.

Axmol Hub is in early access: expect rough edges and breaking changes before 1.0.

  • Windows (64-bit) Windows 10/11, x64
  • macOS (Apple Silicon) macOS 12 or later
  • macOS (Intel) macOS 12 or later
  • Linux x64 Linux x64 (AppImage)

If you have an older version of Axmol Hub installed, uninstall it before installing this version.
