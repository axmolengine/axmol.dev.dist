A command buffer stores encoded commands until the buffer is committed for execution by the GPU

◆ dispatch()

bool dispatch ( const ComputeDispatchDesc & desc)
overridevirtual

Dispatches a compute pipeline on the graphics queue.

The pipeline and program state must reference the same compute program. All resources declared by that program must be bound through the program state before dispatch. The dispatch is submitted outside an active render pass; the RHI performs the required synchronization with subsequent compute and graphics accesses.

Parameters
descCompute pipeline, resource bindings, and workgroup counts.
Returns
true if the dispatch was accepted; otherwise false when compute is unsupported or the descriptor is invalid.
