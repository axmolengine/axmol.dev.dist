◆ getPhase()

InputPhase getPhase ( ) const
inline

Retrieve the phase of this keyboard event.

Returns the input phase that describes the current state of the keyboard interaction, such as when a key is pressed, released, or held in repeat mode.

Returns
InputPhase enumeration value indicating the event phase:
  • InputPhase::KeyDown when the key is pressed
  • InputPhase::KeyUp when the key is released
  • InputPhase::KeyRepeat when the key is repeating
Note
This reflects only the state of this KeyboardEvent instance and does not query the global keyboard state.
