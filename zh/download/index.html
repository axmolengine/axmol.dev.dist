Axmol Hub 抢先体验

Axmol Hub 是官方配套工具，用于安装和管理引擎版本、工具链与构建目标。

Axmol Hub 目前处于抢先体验阶段，1.0 正式版之前可能存在不完善之处与破坏性变更。

  • Windows (64-bit) Windows 10/11，x64
  • macOS (Apple Silicon) macOS 12 及以上
  • macOS (Intel) macOS 12 及以上
  • Linux x64 Linux x64（AppImage）

如果已安装旧版 Axmol Hub，请先卸载旧版，再安装此版本。
