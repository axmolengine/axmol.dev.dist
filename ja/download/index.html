Axmol Hub アーリーアクセス

Axmol Hub は、エンジンのリリース・ツールチェーン・ビルドターゲットをインストールして管理する公式コンパニオンツールです。

Axmol Hub はアーリーアクセス版です。1.0 に向けて未完成な部分や破壊的な変更が含まれる可能性があります。

  • Windows (64-bit) Windows 10/11、x64
  • macOS (Apple Silicon) macOS 12 以上
  • macOS (Intel) macOS 12 以上
  • Linux x64 Linux x64（AppImage）

古い Axmol Hub がインストールされている場合は、先にアンインストールしてから、このバージョンをインストールしてください。
